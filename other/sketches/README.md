# Planning sketches

This folder is reserved for the author's genuine planning sketches. The Donaldson rubric treats sketches as a separate component, so the final submission should contain the sketches actually made during the planning stage.

Recommended files:

- `data_sketch.png` — planned data structure and variables.
- `hourly_delay_sketch.png` — planned main hourly figure.
- `analysis_table_sketch.png` — planned main summary table.

**Do not present computer-generated replacement images as if they were made before the analysis.** Add your own hand-drawn or early digital sketches here and commit them before the final submission.
